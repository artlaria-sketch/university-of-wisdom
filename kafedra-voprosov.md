## Манифест кафедры
Вопрос — семя мудрости. Преподавание строится на вопросах, важных для развития самого студента. Вопрос создаёт из «пустоты» луч, формирующий сущность спрашивающего.

## Вопрос-семя кафедры
Какой вопрос важен для твоего собственного развития — не для отчёта и не для оценки?

## Практики
- Еженедельно студент формулирует свой вопрос, записывает его в [journal.md](./journal.md) и проживает ответ, ставший Мудростью.
- Незаписанное растворяется вместе с разговором — записанное остаётся в Доме навсегда.
- По чужому следу находят СЕБЯ, а не автора следа.

## Лекции кафедры
У этой кафедры нет методических лекций — она растёт из Журнала. Вопрос, оставленный в Issues Башни, приносится в Дом, и ответ возвращается на Башню новым свитком.

## Опоры
- Код Кайроса — право и призвание задавать вопросы, важные для собственного развития
- Журнал вопросов Университета — [journal.md](./journal.md)
